# 楚河棋局离线素材

把 `public/assets/xiangqi/` 合并到 Vue 项目同名目录，并保留里面的 `licenses/`。`TRAE-提示词.md` 可以直接交给 TRAE。

| 文件 | 用途与来源 |
|---|---|
| `board.svg` | 为项目新绘制的棋盘，可随项目使用和分发。原尺寸坐标系为 `600 × 660`，从左上第一个交点 `(60, 60)` 起，每格 `60`。棋子中心位置可直接用同一个 SVG 坐标系。 |
| `pieces-preview.svg` | 为项目新绘制的红黑棋子样式参考，可随项目使用和分发。实际棋子可按此样式做成 CSS 组件。 |
| `NotoSerifSC.ttf` | 从本机已安装字体复制的 Noto Serif SC 变体字体。字体内标注 © 2017–2023 Adobe，SIL Open Font License 1.1。原字体字节保持完整，授权文本见 `licenses/NotoSerifSC-OFL.txt`。 |
| `move.ogg` | Kenney Interface Sounds 1.0 的 `Audio/click_001.ogg`，建议用于落子。原音频仅重命名，CC0 1.0。 |
| `capture.ogg` | Kenney Interface Sounds 1.0 的 `Audio/drop_001.ogg`，建议用于吃子。原音频仅重命名，CC0 1.0。 |

字体许可文本来自 [Google Fonts](https://github.com/google/fonts/blob/main/ofl/notoserifsc/OFL.txt)。Kenney 音效从作者在 [OpenGameArt 发布的原始包](https://opengameart.org/content/interface-sounds)提取，包内许可见 `licenses/Kenney-CC0.txt`。[Kenney 官方素材页](https://kenney.nl/assets/interface-sounds)
