请在当前工作区开发《楚河棋局》，一个能离线运行的中国象棋人机网页小游戏。先检查现有目录和素材，保留已有代码。使用 Vue 3、TypeScript、Vite、Web Worker 和 Vitest。

1. 用 `public/assets/xiangqi/board.svg` 做棋盘。它的 `viewBox` 是 `0 0 600 660`，9 列 10 行交点的坐标是 `x = 60 + 60 × col`、`y = 60 + 60 × row`，从 0 开始，红方在下。让棋盘、棋子、选中态和合法落点提示使用同一坐标系，窗口缩放时保持对齐。参考 `pieces-preview.svg` 用 CSS 做米白双边框棋子，红方朱红字、黑方墨黑字。本地加载 `NotoSerifSC.ttf`、`move.ogg` 和 `capture.ogg`，提供静音开关。保留素材授权文件。
2. 先实现纯 TypeScript 棋规和胜负判定，再接界面。玩家执红先行，点击棋子显示合法落点。双方共用同一合法走法生成器。覆盖各棋子走法、马腿、象眼与过河限制、炮架、九宫限制、将帅照面、自陷将军、解将、将死与困毙。在 README 说明长将和长捉属于首版范围之外。
3. 先用随机合法走法完成一局，再在 Web Worker 中加入 Minimax 与 Alpha-Beta 搜索，提供随机和搜索两档。显示当前回合、电脑思考和胜负状态，并提供重新开始。重开后忽略上一局尚未返回的计算结果。
4. 用 Vitest 覆盖炮隔一子吃子、蹩马腿、撤开将帅间的挡子、被将军时仅允许解将、无合法走法时判负。跑通构建和测试，并实际检查从本机启动后，断开外网仍可走棋、加载素材和让电脑应对。运行时仅使用本地资源，开发阶段可以使用 DeepSeek API 补充测试。更新 README，写明启动命令、规则范围、素材来源和实际验证结果。
